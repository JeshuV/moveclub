# Move Club

A responsive weekly workout planner and optional weight journal. No accounts, dependencies, build step, or sample personal data.

Open index.html in a modern browser, or upload it to the root of a GitHub repository. Enable Settings → Pages → Deploy from a branch → main → / (root).

Plan or complete sessions, record exercises (sets, reps, load), log rest days, and record one weight per week. Click a day to view its journal. Edit and delete controls are available on saved entries.

Data lives in localStorage on the current browser and origin. Back up regularly; clearing browser data removes entries. Restore validates the backup and requires confirmation before replacing the journal. No cross-device sync or medical recommendations.
